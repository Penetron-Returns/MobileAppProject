# Help articles

Short how-to articles for owners of the WhatsApp booking app. Each file has YAML front matter (id, title, tags, optional url) and a markdown body under 4,000 characters. "(verify)" marks anything not confirmed yet. Some articles name the Settings > WhatsApp screens: check them against the current app before relying on them.

| Article | Purpose | When to use it |
| --- | --- | --- |
| [verify-business.md](verify-business.md) | Meta business verification: why, documents, where, how long | Owner asks about limits, display name, "Not verified" or "Pending" |
| [reminders-not-sending.md](reminders-not-sending.md) | Checklist when reminders or confirmations do not arrive | Owner or client says no reminder came |
| [number-quality-and-limits.md](number-quality-and-limits.md) | Quality colors, limit tiers, how to recover | Quality is Yellow or Red, number Flagged, or a limit is reached |
| [reconnect-whatsapp.md](reconnect-whatsapp.md) | Reconnect WhatsApp in Settings > WhatsApp | Status says Reconnect or Not connected, or clients get no reply |
| [display-name-rejected.md](display-name-rejected.md) | Fix a declined WhatsApp display name | Display name shows Declined or Expired |
| [push-notifications.md](push-notifications.md) | Turn on app notifications on Android | Owner is not getting phone alerts |
